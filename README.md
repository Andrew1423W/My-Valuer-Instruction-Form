# My-Valuer-Instruction-Form
Instruction form for staff

## Repository contents

- `index.html` — the staff valuation instruction form (Microsoft 365 sign-in,
  SharePoint-backed job archive, quote and email generation).
- `platform/` — the My Valuer practice platform: job pipeline, inspections,
  sales and rental evidence, and Word report assembly, on Next.js and
  PostgreSQL. See [platform/README.md](./platform/README.md).
